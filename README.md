# tomalmog.com

A plain text page: name, links, one line per thing I've worked on. White
background, black text, moon icon in the corner toggles dark mode (saved to
localStorage).

## Tech

- Next.js 14 (App Router)
- Homepage is plain CSS in `app/globals.css`; system fonts, no web fonts
- Tailwind is still compiled for the `/bmm` and `/tempo` routes

Also hosts `/bmm`, `/tempo`, and `/committrader`.

## Develop

```bash
npm run dev    # local dev server
npm run build  # production build
```
