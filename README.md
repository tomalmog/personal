# Tom Almog - Personal Portfolio

A unique RPG/pixel art themed portfolio website featuring an AI-powered chatbot.

## Features

- 🎮 Retro RPG aesthetic with pixel art styling
- 🤖 AI chatbot powered by Groq (Llama 3.1)
- 📱 Fully responsive design
- ⚡ Fast serverless architecture
- 🔒 Secure API key handling

## Sections

- **About** - Introduction and chatbot
- **Education** - Academic background
- **Experience** - Work history
- **Projects** - Portfolio of work
- **Skills** - Technical abilities
- **Awards** - Achievements
- **Interests** - Personal hobbies
- **Contact** - Get in touch

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Press Start 2P font
- Groq API for AI chatbot
- Netlify Functions for serverless backend

## Deployment

See [DEPLOYMENT.md](./DEPLOYMENT.md) for complete deployment instructions.

## Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. For chatbot functionality, deploy to Netlify or use `netlify dev`
